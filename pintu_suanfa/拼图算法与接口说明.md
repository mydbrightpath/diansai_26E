# 拼图算法与视觉、控制接口

本实现针对题目中的 1~4 片直边碎片、每片 3~5 个顶点、每片至少一条矩形外边。现场目标长边 90~120 mm、短边 50~90 mm。题目允许相邻对应顶点误差不超过 20 mm，但算法默认追求毫米级几何误差，不能将 20 mm 当作轮廓误差预算。代码只生成移动任务，不包含特定机械臂通信协议。

## 文件与运行

- `puzzle_solver.py`：输入校验、多边形三角化、交叠面积、边对齐、回溯、矩形检查、抓放任务输出；函数均带中文说明。
- `pattern_score.py`：接缝颜色连续性评分基线，作为几何多解排序依据。
- `test_solver.py`：几何与坐标接口回归测试。
- `requirements.txt`：依赖，仅 NumPy。

```bash
python -m pip install -r requirements.txt
python -m unittest -v test_solver.py
python puzzle_solver.py
```

演示是合成数据，不能代替现场识别和机械臂实验。代码可在 PC/树莓派等运行 Python 的主机上求解，随后发送任务给下位机；不是 STM32 可直接烧录的固件。

## 视觉必须提供哪些数据

先校正镜头畸变，再以 A4 四角建立纸面毫米坐标。建议左上为 (0,0)，右下为 (210,297)，x 向右，y 向下。所有碎片顶点和抓取点必须来自同一帧、同一坐标系。不要把像素直接当作毫米；只在图像无透视时才可使用简单比例换算。

| 输入 | 单位/形式 | 用途 |
|---|---|---|
| `id` | 唯一字符串 | 跟踪碎片，关联图像与下位机动作 |
| `vertices_mm` | 3~5 行，每行 [x,y] | 真实拐角，沿边界顺序排列，不能按 x 排序 |
| `pick_mm` | [x,y]，毫米 | 吸盘/夹爪的实际作用点，必须在可抓区域内 |
| `source_yaw_rad` | 弧度，默认 0 | 若使用夹爪，表达当前工具对准碎片的方向 |

求解器会将顺时针顶点转为数学逆时针。不要重复首顶点；去掉连续重复点、接近共线点和毛刺；凹片必须保留真实凹角。先直线拟合，再求交点，比直接用轮廓像素更适合这个求解器。上表的抓取点应离边缘大于吸盘半径加余量；凹片面积质心可能在外面，所以不能无条件使用质心。本实现只验证点在片内，吸盘余量由视觉负责。

视觉还应在外围逻辑给出 `frame_id`、时间戳、检测数量、轮廓拟合残差、遮挡状态和标定有效性。求解前检查碎片不重叠、不出上半区且数量符合任务。现有求解函数不消费这些字段，需要你的主程序检查。

若要处理扑克牌，必须保留校正后的彩色图像、碎片 mask，以及毫米坐标到该图像像素的映射。`make_pattern_scorer` 需要 `sampler(id, points_mm)` 返回 N×3 RGB，范围 0~1；采样来自原始识别帧，不能来自机械臂移动后的旧位置。

## 接入示例

```python
import numpy as np
from puzzle_solver import Piece, solve, make_tasks
from pattern_score import make_pattern_scorer

# detections 是视觉模块的输出；顶点和抓点均已转为纸面毫米坐标。
pieces = [Piece(str(d['id']), np.array(d['vertices_mm']),
                np.array(d['pick_mm']), d.get('source_yaw_rad', 0.0))
          for d in detections]

# 纯色场景不用 scorer。图案场景由视觉实现双线性 RGB 采样函数。
# scorer = make_pattern_scorer(sample_rgb_in_original_frame)
result = solve(pieces)  # 或 solve(pieces, pattern_score=scorer)
if not result['solutions']:
    raise RuntimeError('未找到可执行的拼图方案：' + result['status'])
chosen = result['solutions'][0]
tasks = make_tasks(pieces, chosen, target_origin_mm=[45,180])
# tasks 可用 json.dumps 序列化；执行前仍需完成下面的坐标转换与检查。
```

目标原点与角度由你选择。`make_tasks` 默认要求所有顶点在纸张下半区 y>=148.5；实际分界线有宽度，应修改 `paper_bounds` 留余量。默认原点不是自动最优位置。矩形整体旋转 90 度可能更适合机械臂工作区，可通过 `target_yaw_rad` 设置，再做越界检查。

## 求解原理及参数

1. 不知道每片属于哪个位置，枚举第一片和它的某条边，将这条边转到水平。题目每片有外边，使水平种子假设有依据。
2. 对待放片与每个已放片枚举边，将两边方向转成相反方向，再枚举端点对齐。长边与短边可以只部分重合，支持 T 形接缝。
3. 接触长度不足则拒绝；用三角化加凸多边形裁剪计算交叠面积，拒绝重叠。
4. 递归枚举下一片，包围盒超过允许尺寸立即剪枝。
5. 全部放入后，检查矩形长短边范围，以及碎片总面积和包围盒面积的一致性。去重后按图案分数、面积缺口排序。

`Config` 中 `area_gap_fraction=0.015` 是相对面积缺口门限，`overlap_mm2=0.5` 是每对碎片交叠面积门限，`dimension_tolerance_mm=1` 是尺寸门限余量，`min_contact_mm=3` 是最短接触长度。这些是工程初值，应根据实际拟合误差调整，不能保证满足最终顶点距离评分。

默认最多搜索 12 秒/100000 节点/32 个候选，为 2 分钟总流程留时间。返回 `search_complete=False` 表示触发了某个上限；已发现的候选仍可以几何复核，但不代表找到全部解或图案最优解。`no_solution` 表示有限候选空间未找到矩形，`limit_reached` 表示提前停止且尚无解。

本方法只枚举端点对齐的有限候选。它适合小规模、直边且拐角拟合准确的拼图，但不是任意多边形切割的完备求解器；未知切割可能需要沿共线边增加滑移参数搜索。实测轮廓的角度/长度误差也会使严格接触不成立，当前版本没有联合优化所有顶点。现场若稳定无解，应先检查毫米标定、轮廓拟合，再考虑约束优化，而不是盲目放宽重叠。

## 图案部分的实际能力

`pattern_score.py` 在公共边两侧取样，逆变换回原图，计算 RGB 差异，分数越大越好。它提供可运行的基线，能给部分几何多解排序，但白底、重复花纹、接缝处本来就有颜色变化均会误判；没有图案信息时不能声称完成扑克牌花纹还原。

建议保存全部候选拼接预览，并用实拍牌面验证分数是否区分正确/错误方案。若有目标牌面模板，用整体图像配准比单纯接缝连续性更可靠。没有模板时可增加接缝多行颜色/梯度延拓、牌面符号结构评分，并设置分数差门限；差值不够时应自动重新识别/增加图案判别，禁止靠候选顺序直接确定花纹。

## 输出给控制模块哪些东西

| 输出 | 含义 |
|---|---|
| `piece_id` | 本动作对应的碎片 |
| `pick_xy_mm` | 当前抓取点在纸面坐标中的位置 |
| `place_xy_mm` | 同一个材料点放置后的位置 |
| `delta_yaw_deg` | 从当前状态到目标的旋转增量，范围 [-180,180) |
| `source_yaw_deg` / `target_yaw_deg` | 当前/目标工具对准方向，仅在视觉给定方向基准后有效 |
| `source_to_target_R` / `source_to_target_t_mm` | 任意碎片材料点的刚体变换 q=R p+t |
| `target_vertices_mm` | 最终完整轮廓，便于控制碰撞检查和视觉复核 |
| `width_mm` / `height_mm` | 当前候选矩形尺寸 |

关键：`place_xy_mm` 是原抓取点随碎片变换后的点，不一定是目标片质心。若抓偏质心、仍把目标质心当作吸盘落点，会拼错位置。

在 x 向右、y 向下的纸面图上，正旋转表现为顺时针。机械臂坐标系一般不同，不能原样发送这个角度。标定纸面到机械臂基座的变换：

```text
P_robot = R_robot_from_paper · [x_paper, y_paper, 0] + t_robot_from_paper
```

二维纸面工具方向 `[cos(yaw),sin(yaw),0]` 同样乘该旋转矩阵，再按机械臂 TCP 方向约定求工具姿态。若采用反射的二维坐标映射，角度正负也会改变。Z 高度、吸盘长度、抓取下降量、工具零位、释放高度应由控制模块根据实机标定加入。

## 控制执行与闭环

任务数组当前按输入 id 对应顺序输出，没有优化机械臂动作顺序。建议在控制端选择可达、容易抓取的顺序，必要时按目标空隙/夹爪尺寸调整。每次：移动到当前抓点上方 → 下降 → 吸取并确认 → 抬升到安全高度 → 空中移动和旋转 → 到目标上方 → 下降 → 释放 → 抬升。路线、速度、Z 和碰撞检测由控制端负责。

选解时整体检查目标区域未被其他物体占用。每抓一片后，视觉重新确认剩余碎片位置及 id；若吸取扰动了其他片，更新源姿态并重算该片到原定目标的变换，不要继续用旧帧抓点。可用顶点/轮廓配准得到当前到既定目标的 R、t。

放置后拍照，计算实测轮廓到 `target_vertices_mm` 的配准误差；超限则做一次小幅校正。吸取失败、定位失效或任务超时应返回失败状态。最终检查所有片到下半区、无重叠、矩形尺寸、相邻对应顶点距离，以及图案模式下花纹一致性，再发完成声光信号。搜索里的面积门限不能替代这些实物验收检查。

建议串口消息增加 `task_id`、`sequence`、`frame_id` 和 CRC，并让下位机返回 ACK/抓取成功/放置成功/失败原因。当前示例 JSON 没有实现协议握手，需按你的机械臂通信协议封装。
