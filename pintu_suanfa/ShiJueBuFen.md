你作为视觉部分，最核心的工作就是：

**拍一张照片，找出每块碎片的轮廓，并把“照片上的像素位置”转换成“A4 纸上的毫米位置”，然后交给拼图算法。**

你不需要在视觉部分决定“这块碎片最终放在哪”。那是拼图算法的工作。

先把整个系统理解成下面这条流程：

```text
相机拍照
    ↓
视觉：找碎片、找顶点、找抓取点
    ↓
视觉：像素坐标转换成纸面毫米坐标
    ↓
拼图算法：计算每块碎片应该放在哪里、旋转多少
    ↓
控制模块：让机械臂抓取、旋转、放置
```

下面按你实际要做的顺序来讲。

## 1. 你最终需要提供什么信息？

对于每一块碎片，你至少提供三个信息：

| 信息 | 简单解释 | 举例 |
|---|---|---|
| `id` | 这块碎片的编号 | `"piece_0"` |
| `vertices_mm` | 这块碎片所有拐角在 A4 纸上的位置 | `[[30,20], [70,20], [50,50]]` |
| `pick_mm` | 机械臂应该抓这块碎片的哪个位置 | `[50,30]` |

这里所有位置的单位都是 **毫米**。

比如下面是一块三角形碎片：

```python
{
    "id": "piece_0",

    # 三个顶点在 A4 纸面上的位置，单位：毫米
    "vertices_mm": [
        [30.0, 20.0],
        [70.0, 20.0],
        [50.0, 50.0]
    ],

    # 抓取点在 A4 纸面上的位置，单位：毫米
    "pick_mm": [50.0, 30.0]
}
```

你提供的是碎片**现在的位置和形状**。

拼图算法会根据这些数据，算出这块三角形最终应该放在哪。

**碎片边长、面积、旋转角、最终位置，不需要你额外算好再传入。**算法可以从顶点坐标中得到这些几何信息。

## 2. 先理解两种坐标：像素坐标和纸面坐标

这是整个视觉接口里最容易弄混的地方。

### 2.1 相机给你的是像素坐标

比如相机拍出来的图片是：

```text
宽：1280 像素
高：720 像素
```

在这张图片里，一个碎片顶点的位置可能是：

```text
u = 420
v = 180
```

意思是：

- 从图片左边向右数 420 个像素；
- 从图片上边向下数 180 个像素。

通常记作：

```python
[u, v] = [420, 180]
```

**这个位置不能直接交给当前拼图算法。**

因为算法需要毫米，而不是像素。

### 2.2 拼图算法需要的是纸面毫米坐标

我们给 A4 纸建立一个统一坐标系：

```text
A4 纸左上角：       (0, 0)
A4 纸右上角：       (210, 0)
A4 纸右下角：       (210, 297)
A4 纸左下角：       (0, 297)
```

约定：

- `x` 向右增大；
- `y` 向下增大；
- 单位为毫米。

例如：

```python
[x, y] = [50, 30]
```

表示这个点距离 A4 纸左边 50 mm，距离上边 30 mm。

**你要完成的关键转换就是：**

```text
图片位置 [u, v]
        ↓
A4 纸面位置 [x, y]，单位 mm
```

同一个碎片的所有顶点和抓取点，都必须使用这个坐标系。

## 3. 怎么把像素坐标转换成毫米坐标？

最容易理解的办法是：**利用 A4 纸四个角做标定。**

### 3.1 先找出图片里 A4 纸的四个角

你在相机图片里找出：

```text
左上角
右上角
右下角
左下角
```

假设你检测到的像素坐标是：

```python
paper_corners_px = [
    [180,  60],   # 左上
    [950,  85],   # 右上
    [990, 690],   # 右下
    [150, 670]    # 左下
]
```

这里数字只是演示，实际要由你的相机画面得到。

这四个点对应的真实位置是：

```python
paper_corners_mm = [
    [0,   0],
    [210, 0],
    [210, 297],
    [0,   297]
]
```

这样你就有了四组对应关系：

```text
图片左上角位置 → 纸面 (0,0)
图片右上角位置 → 纸面 (210,0)
图片右下角位置 → 纸面 (210,297)
图片左下角位置 → 纸面 (0,297)
```

利用这些对应关系，就可以建立**平面透视变换**。

你暂时不必理解它的数学推导。可以把它理解成：

> 相机看到的纸可能是歪的、近大远小的，这个变换把它恢复到标准 A4 纸面坐标。

### 3.2 A4 四角怎么获得？

建议你分两步做。

**第一步：调试时手动选角。**

在一张相机图片上，手动点击 A4 的四个角，先把坐标转换流程跑通。

这样你可以先判断算法和坐标有没有问题，不必一开始就同时解决所有识别困难。

**第二步：正式运行时自动检测。**

利用 A4 纸与背景之间的颜色或亮度差异，找出纸张轮廓，再得到四个角。

如果相机和纸张的位置固定，标定数据可以复用。但只要相机或纸张移动了，就应重新检查或更新标定。

题目要求自动运行，所以手动选角适合开发和调试；最终测评的运行流程不能依赖现场手工点击。

### 3.3 怎么确认毫米转换是对的？

不要只看“转换后的图像像不像矩形”。

你可以在纸面不同位置放一个已知尺寸的物体，例如一条 50 mm 的线段，检查转换后测出的长度是否接近 50 mm。

至少检查：

- 纸张中央；
- 左上附近；
- 右上附近；
- 下半拼图区。

如果中央准确、边缘明显不准确，可能存在镜头畸变。镜头畸变要先校正，再做纸面透视变换。

还要注意：碎片在纸面上方有一定厚度。相机倾斜越明显、安装越低，厚度造成的位置误差越容易出现。因此调试时尽量让相机接近正上方，并保持安装稳定。

## 4. 怎么从图片里找出碎片？

你先需要得到一张“哪里是碎片，哪里是背景”的图。

这张图叫 **mask，或者二值掩膜**。

### 4.1 mask 是什么？

它可以简单理解成：

```text
属于碎片的像素：白色
不属于碎片的像素：黑色
```

原图：

```text
有颜色、有纹理、有阴影的照片
```

mask：

```text
只留下每块碎片的形状
```

这样就能从 mask 中找出每一块独立的碎片。

### 4.2 新手应该怎么区分碎片和背景？

核心是让它们在图像里有明显区别。

例如：

- 白色碎片放在颜色明显不同的纸上；
- 同色碎片与纸张之间具有足够的颜色差异；
- 相机固定曝光和白平衡后，减少画面变化。

你可以根据颜色或亮度，判断每个像素是否属于碎片。

但不要一开始就追求一个固定阈值适用于所有情况。题目要求适应正常室内照明，你需要用不同室内光照的实拍图片验证。

扑克牌碎片有一个特别容易遇到的问题：

> 白色纸片上有黑色、红色图案。如果只保留白色像素，牌面图案会变成 mask 内的“洞”。

因此，碎片检测应尽量得到**完整的外轮廓**，不能把牌面上的每一个黑色符号当成独立物体。

### 4.3 找到每块碎片后，你会得到什么？

你会得到一个轮廓点列表，例如：

```python
contour_px = [
    [420, 180],
    [421, 180],
    [422, 181],
    ...
]
```

这可能有几百个点，沿着碎片边缘排列。

**这个完整轮廓还不能直接作为 `vertices_mm` 传入。**

当前拼图算法需要的是碎片真正的 3～5 个拐角。

## 5. 怎么从几百个轮廓点中得到 3～5 个顶点？

你可以把这一步理解成：

> 用几条直线去描述碎片边缘，再找出这些直线的交点。

### 5.1 先做多边形近似

一块三角形的边缘可能有很多像素点，但它本质上只有三条边、三个角。

多边形近似会把：

```text
几百个轮廓点
```

压缩成：

```text
几个拐角
```

例如：

```python
vertices_px = [
    [420, 180],
    [610, 195],
    [500, 330]
]
```

这就是三角形的三个像素顶点。

### 5.2 更稳定的方法是拟合直线

实际照片的边缘可能有：

- 阴影；
- 毛刺；
- 像素锯齿；
- 高光；
- 切割边缘不整齐。

直接取近似后的角点，位置可能会跳动。

所以比较稳的流程是：

```text
提取轮廓
    ↓
多边形近似，找到大致边和角
    ↓
用每条边附近的轮廓点拟合直线
    ↓
相邻直线求交点
    ↓
得到更稳定的顶点
```

你作为初学者可以先实现多边形近似，成功后再增加直线拟合。

### 5.3 顶点应该按什么顺序传？

必须**沿碎片边界顺序排列**。

例如四边形：

```text
沿边走：顶点1 → 顶点2 → 顶点3 → 顶点4
```

顺时针或者逆时针都可以，现有代码会处理方向。

但不要：

- 按 `x` 从小到大排序；
- 按距离原点远近排序；
- 把首顶点再重复放到末尾；
- 把凹进去的角删掉。

凹形碎片的凹角决定了形状，必须保留。

### 5.4 最后转成毫米坐标

把每个像素顶点经过前面建立的坐标变换：

```text
vertices_px
    ↓
vertices_mm
```

最终得到：

```python
vertices_mm = [
    [30.0, 20.0],
    [70.0, 20.0],
    [50.0, 50.0]
]
```

这就是拼图算法最重要的输入。

## 6. 抓取点 `pick_mm` 怎么获得？

抓取点就是：

> 你希望吸盘或夹爪实际作用在碎片上的那个位置。

它不一定是碎片中心。

### 6.1 如果你用吸盘

对于新手，建议先理解一种实用方法：

**找出碎片内部距离边缘最远的位置。**

原因是吸盘有大小。抓取点太靠近边缘，吸盘可能有一部分落在碎片外面，导致漏气或抓取失败。

可以在碎片 mask 中计算每个内部像素到最近边缘的距离。

比如：

```text
靠近边缘的点：距离小
靠近宽阔内部的点：距离大
```

选择距离最大的点作为抓取点候选，再把它转换成毫米坐标。

不过，吸盘是一个圆形区域，所以还要检查：

```text
抓取点到边缘的距离
    >
吸盘半径 + 定位误差余量
```

举例：

```text
吸盘半径：4 mm
预留余量：2 mm
```

那么抓取点最好距离边缘至少 6 mm。

这是举例，实际数值要根据你的吸盘和识别误差确定。

### 6.2 为什么不直接用轮廓中心？

对于三角形、普通凸多边形，面积质心常常可以作为候选点。

但对于凹形碎片，质心可能落在碎片外面，或者离边缘太近。

因此更建议检查“吸盘能不能完整放进去”，而不是只计算一个中心就直接执行。

### 6.3 如果你用夹爪

情况会比吸盘复杂一些。

你需要考虑：

- 夹哪两条边；
- 夹爪张开宽度；
- 夹爪朝向；
- 周围是否有其他碎片阻挡。

这时仅提供一个 `pick_mm` 不足以定义完整抓取动作，还需要抓取方向等信息。

当前代码中的 `source_yaw_rad` 就可以表达方向，但具体夹持方式需要和机械臂控制人员统一约定。

**如果你的装置用的是圆形吸盘，可以先不研究这个方向参数，重点完成轮廓和抓点。**

## 7. 碎片编号 `id` 怎么获得？

第一次拍照时，检测到几块碎片，就给它们编号：

```text
piece_0
piece_1
piece_2
piece_3
```

编号不表示拼图中的位置，也不表示形状类型。

它只是让视觉、拼图算法和控制部分能够明确：

> 大家现在说的是同一块碎片。

第一次识别后，一旦机械臂开始移动，就不要每拍一张照片重新按轮廓顺序编号。

因为重新检测的顺序可能变化，原来的 `piece_0` 可能被错误地换成另一片。

初期你可以用“原位置附近匹配 + 外形匹配”跟踪剩余碎片。如果移动过程中有明显扰动，则需要更可靠的跟踪和重新定位。

## 8. 扑克牌图案还需要提供什么？

纯色碎片主要依靠轮廓几何。

扑克牌碎片还要求花纹对应，因此视觉除了几何信息，还应保留：

1. **原始彩色图像**；
2. **每片的完整 mask**；
3. **毫米位置到图像像素位置的转换关系**。

为什么还需要第三项？

因为拼图算法会说：

> 我想检查这片碎片某条边附近的颜色。

它给出的检查位置是毫米坐标。视觉需要知道这个毫米位置对应原图的哪个像素，再返回该位置的 RGB 颜色。

我之前提供的图案评分代码使用的接口是：

```python
sampler(piece_id, points_mm)
```

例如：

```python
points_mm = [
    [40.0, 25.0],
    [41.0, 25.0],
    [42.0, 25.0]
]
```

视觉返回：

```python
[
    [1.0, 1.0, 1.0],  # 白色
    [0.0, 0.0, 0.0],  # 黑色
    [1.0, 0.0, 0.0]   # 红色
]
```

这里 RGB 使用 `0～1` 范围。

你可以先把纯色拼图做通，再做图案。现有接缝颜色评分只是基础方案，白底和重复图案仍可能让它分不清正确解。

## 9. 你不需要替拼图算法做哪些事情？

为了避免你承担过多工作，这里把分工明确一下。

| 工作 | 负责部分 |
|---|---|
| 找 A4 纸位置 | 视觉 |
| 像素转换成纸面毫米 | 视觉 |
| 找到每块碎片 | 视觉 |
| 得到每块碎片的顶点 | 视觉 |
| 找到可靠抓取点 | 视觉 |
| 算碎片之间怎么拼 | 拼图算法 |
| 算目标位置和旋转增量 | 拼图算法 |
| 纸面坐标转换成机械臂基座坐标 | 控制/标定部分协作完成 |
| 机械臂如何运动、下降、吸取 | 控制 |
| 放完后检查是否到位 | 视觉 |
| 根据误差再次移动 | 视觉、算法和控制共同完成 |

尤其要注意：

**你不需要先判断这块碎片应该放在矩形左上角还是右下角。你只需要准确描述它当前的形状和位置。**

## 10. 最推荐你按这个顺序开发

不要第一天就把“自动识别、图案、机械臂、闭环”一起做。

建议分成以下几个可验证的阶段：

### 第一步：先把坐标转换做对

暂时不用碎片。

- 拍到完整 A4 纸；
- 手动选择四个角；
- 建立纸面坐标转换；
- 用已知尺寸检查测量误差。

完成标准：照片上的点能够可靠地转换成毫米位置。

### 第二步：只识别一块三角形

- 得到碎片 mask；
- 找外轮廓；
- 提取三个顶点；
- 转换成毫米；
- 在画面上标注三个顶点。

完成标准：实际是三角形，程序稳定给出三个正确角，而不是五个、十个。

### 第三步：给这块碎片找抓取点

- 找内部安全点；
- 检查吸盘能否完整落在碎片内；
- 转换成毫米；
- 在画面上画出吸盘覆盖范围。

完成标准：抓取点和吸盘范围都在碎片内部。

### 第四步：识别四块碎片并输出数据

最终视觉输出可以是：

```python
detections = [
    {
        "id": "piece_0",
        "vertices_mm": [
            [30.0, 20.0],
            [70.0, 20.0],
            [50.0, 50.0]
        ],
        "pick_mm": [50.0, 30.0]
    },

    # 其他碎片按同样格式提供
]
```

然后交给已有算法：

```python
import numpy as np
from puzzle_solver import Piece, solve

pieces = [
    Piece(
        id=d["id"],
        vertices_mm=np.array(d["vertices_mm"], dtype=float),
        pick_mm=np.array(d["pick_mm"], dtype=float)
    )
    for d in detections
]

result = solve(pieces)
```

### 第五步：先在电脑上显示求解结果

暂时不用机械臂。

把算法求出的目标顶点画出来，确认：

- 所有碎片组合成矩形；
- 没有明显重叠；
- 外形尺寸合理。

### 第六步：再接机械臂和放置后检查

先测试单片抓取和毫米定位，再测试多片拼接，最后增加放置后的视觉复测。

你现在最应该先完成的交付物就是：**一张标注了 A4 四角、每片顶点、每片抓取点的照片，以及对应的毫米坐标数据。**这两样正确了，视觉和拼图算法之间的接口就基本打通了。
